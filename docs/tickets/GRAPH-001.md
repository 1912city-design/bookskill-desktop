# GRAPH-001：从蒸馏结果生成可交互知识图谱（P1）

- ID：GRAPH-001
- 阶段：E
- 目标：蒸馏完成后，用规则（可辅以可注入的模型适配）抽取节点与边，在「知识库」内提供可交互图谱视图；点击节点跳到对应段落。生命图谱按书聚合。
- 负责人 Agent：ai_skill_engineer（核心抽取）与后续 frontend 视图工单，若本票只做核心则前端另开 GRAPH-002。本票先按 **Backlog** 排队，P0 的 DISTILL-001 / COUNCIL-001 开出 PR 后再开工。
- 依赖：DISTILL-001
- 状态：Backlog
- 风险等级（预估）：中（若只存图 JSON 于数据目录则不改 schema；若要新表则升为高风险并走 D-025）
- 测试样本：3 本定稿夹具。不得改原件。

## 数据模型

```json
{
  "nodes": [{"id": "n1", "type": "principle", "label": "...", "book_id": "...", "source_section": 1, "source_filename": "..."}],
  "edges": [{"source": "n1", "target": "n2", "type": "applies_to"}]
}
```

节点类型应对齐锁定 5 段（定位/原则/金句/框架/Skill），不要改用未锁定的段名。

## 验收条件（草稿，开工前再冻结）

1. 3 本定稿合计节点 ≥30，边可解释，点击所需的段落定位存在（或明确标未确认）。
2. 新增一本已校验的蒸馏后，图谱可更新。
3. 独立 QA 通过前不得合入，不得宣布完成。

## 禁止

- 改锁定模板与定稿原件；AnythingLLM 内部库当业务图存储；第六个一级导航（图谱放在知识库视图内，除非产品另作确认）。
