# APP-001：桌面骨架

- ID：APP-001
- 目标：产品名称、导航、设置、错误边界和测试安装包。Windows/macOS 开发构建可启动，创建 BookSkill 数据目录，不覆盖上游用户数据。
- 负责人 Agent：frontend_engineer
- 依赖：REPO-001
- 输入/受影响模块：桌面壳、导航、设置、数据目录初始化
- 允许工具：基于已审计的 AnythingLLM 源码做适配层上的桌面壳；本地开发构建与测试
- 禁止操作：重新包装官方桌面二进制；写入上游用户数据目录；推送 main；发布正式版
- 状态：Backlog
- 验收条件（可测试）：
  1. 应用显示产品名 BookSkill Desktop，并提供五个一级入口：问题对话（默认）、书库、知识库、Skills、设置与数据。
  2. 存在错误边界，启动失败时有可见错误而不是白屏。
  3. 首次启动在独立的 BookSkill 数据目录创建结构，路径可测试且不使用 AnythingLLM 默认用户目录。
  4. 至少一个目标 OS 的开发构建可启动；若仅有 Linux 中间构建，必须标明未满足正式 G1 目标 OS 条件。
- 测试命令：以当时 `docs/DEVELOPMENT.md` 为准的开发构建与冒烟测试。
- 交付物路径：桌面壳源码、测试安装包或开发构建产物路径、`docs/` 下的任务报告。
- 失败升级条件：目标 OS runner 不可用则 BLOCKED 该项，保留 Linux 中间证据，不扩大范围。
