## 验收条件（可测试）

1. 角色配置只包含合同中的 8 个角色，并写明各自允许/禁止操作；测试拒绝未知角色。
2. 工具清单显式排除：合并主分支、生产发布、读取生产密钥、删除线上数据。调用这些被禁工具时必须失败并写入审计日志。
3. 任务状态可持久化，覆盖状态机中的合法迁移；非法迁移被拒绝。
4. 预算、重试（最多 2 次）、超时有配置并有测试。
5. 审计日志记录任务 ID、角色、动作、时间、结果；不得写入密钥明文。
6. 远端「可创建 PR 并读取 CI」若因发布仓库未连接而无法演示，必须在报告中标为 BLOCKED（引用 B-001 / B-007），不得标 Done。
