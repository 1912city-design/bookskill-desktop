## 验收条件（可测试）

1. 对两张已存在的知识卡，可以生成一条关系**建议**；建议在确认前不得以正式关系出现在“已确认关系”列表中。
2. 用户确认后，关系以正式状态写入 `knowledge_relations`，且 `relation_type` 为允许集合之一（至少含 `supports` / `contradicts` / `example_of` / `related_to`）。
3. 用户可以驳回建议；驳回后不得残留为正式关系。
4. 删除任一端知识卡时，既有删除契约仍成立（相关关系行被清理）；本票不得削弱该行为。
5. 自动化测试覆盖建议 → 确认、建议 → 驳回、非法自环（`from_card_id = to_card_id`）被拒绝；失败时非零退出。
