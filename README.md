# BookSkill Desktop

本地优先的桌面知识产品：导入书籍/笔记 → 阅读和标注 → 提炼可追溯知识卡 → 组合成 Skill → 在对话中调用 → 保存结果与反馈 → 迭代 Skill。

> 状态：**本地工作区草案**。发布仓库尚未连接。本目录还不能用于远端 PR 或正式安装包发布。
